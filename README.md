# AEObility — Remotion Video Reel

7 Core Principles That Get Your Brand Cited in AI Search.

Built with [Remotion 4.x](https://www.remotion.dev/) (React + TypeScript).

## Quick Start (Codespace or Local)

### 1. Install dependencies
```bash
npm install
```

### 2. Launch Remotion Studio (Interactive Preview)
```bash
npm start
# or: npx remotion studio
```

### 3. Render MP4 Videos
- **5-second Hero Poster Loop** (1080x1350 @ 60fps):
  ```bash
  npm run render:hero
  ```
- **Full 8-Scene Breakdown Reel** (Hero + 7 Core Principles):
  ```bash
  npm run render:reel
  ```

## Compositions
- `AEOHeroPoster`: 5-second 1080x1350 4:5 portrait animated loop.
- `AEOFullReel`: Complete 8-scene sequenced reel (24 seconds @ 60fps).
